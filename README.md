## 📌 Overview

**CMS (Collage/College Management System)** is designed to digitize and simplify the daily operations of educational institutions — including student records, faculty workflows, attendance, announcements, and more.

Built primarily using **Dart (Flutter)**, the project targets a responsive and scalable experience across platforms.

---

## ✨ Key Features

- 👨‍🎓 **Student Management**
  - Add/update student profiles
  - Enrollment and class allocation
  - Track academic details

- 👩‍🏫 **Faculty Management**
  - Manage faculty records
  - Assign departments and subjects
  - View teaching schedules

- 🏫 **Department & Course Management**
  - Organize departments
  - Create and map courses
  - Semester/session tracking

- 🗓️ **Attendance & Scheduling**
  - Record attendance
  - Timetable handling
  - Session planning

- 📢 **Notices & Communication**
  - Post announcements
  - Share updates with students/faculty

- 🔐 **Authentication & Roles** *(if implemented)*
  - Admin/Faculty/Student access separation
  - Role-based permissions

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Dart SDK (comes with Flutter)
- Android Studio / VS Code
- Emulator or physical device

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/amitmahato98/CMS.git
   cd CMS
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```
